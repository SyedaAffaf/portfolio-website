# Personal Portfolio Website

## Project Description
A modern, responsive personal portfolio website built with HTML5 and CSS3 as Task 01 of the Devixo Solutions Web Development Internship. <!-- TODO: add one or two sentences in your own words -->

## Technologies Used
- HTML5 (semantic elements)
- CSS3 (Flexbox, Grid, media queries, transitions)
- Git & GitHub

No CSS frameworks or templates were used.

## Features
- Responsive layout for desktop, laptop, tablet, and mobile
- Fixed navigation bar with smooth scrolling and a mobile menu
- Hero section with name, tagline, and call-to-action
- About, Skills, Education, Projects, and Contact sections
- Skill cards with progress bars
- Project cards with hover animations
- Contact form UI (no backend)
- Footer with quick links and social links
